# Donanım ve Mekanik Tasarımlar

Bu dizin, projenin fiziksel yapısını oluşturan bileşenleri barındırır:

1. **PCB Tasarımları**: Mikrodenetleyici ve sensör entegrasyonu için özel devre şemaları (KiCad / Eagle / Fritzing).
2. **Mekanik Parçalar**: 3D yazıcı ile basılabilecek servo motor/pnömatik valf bağlantı aparatlarının STL dosyaları.
3. **Şemalar**: Bant sisteminin genel yerleşim şeması.

*Lütfen yeni donanım şemalarını eklerken standart CAD formatlarını kullanmaya özen gösterin.*
